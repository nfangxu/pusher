# 压测报告

**测试时间：** 2026-05-25
**测试环境：** macOS (Darwin 24.6.0), Apple Silicon
**服务配置：** 默认配置 (worker_num=8, shard_num=32, rate_limit=100 QPS)
**业务场景：** 低推送量、高连接数

---

## 场景 1：连接建立压测

| P99 | 394ms |

### 10,000 连接

| 指标 | 数值 |
|------|------|
| 总连接数 | 10,000 |
| 并发数 | 2,000 |
| **成功率** | **100.00%** |

**结论：** 10000 并发连接全部成功，高并发下 P95/P99 升高属正常现象。

## 总结

| 测试项 | 结果 |
|--------|------|
| 连接建立 (10,000) | 100% 成功, 4205 QPS |
| 单用户推送 | 100% 成功, P99=3ms |
| Channel 推送 | 100% 成功, P99=4ms |
| 稳定性 (2,000连接/1分钟) | 100% 成功, P99=232ms |
| 稳定性 (5,000连接/1分钟) | 100% 成功, P99=708ms |
| 稳定性 (10,000连接/1分钟) | 100% 成功, P99=1.062s |

**核心指标（低push多连接场景）：**
- 支持 10,000 并发 SSE 连接
- 全量广播推送成功率 100%，无 panic
- 单用户推送延迟 P99 < 5ms
- 万级连接下全量推送 P99 ≈ 1s

**待优化项：**
- 全量广播 fan-out 到万级连接时延迟较高，可考虑异步 fan-out 或分批发送
- 压测工具 `holdConnections` 使用 raw TCP 维持连接，大量连接时实际 QPS 低于目标值（fan-out 耗时 > 推送间隔）
